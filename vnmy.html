VNMY.

движок визуальных новелл

Не хватает собранных файлов

С телефона проще всего открыть vnmy.html — это тот же движок одним файлом: движок, стили, истории и картинки внутри. Рядом ничего не нужно, собирать ничего не надо.

Если открываете index.html, движку нужны bundle.js и stories/builtin.js — браузер не грузит ES-модули с file://. Вселенные лежат в stories/<вселенная>/.

Соберите их один раз:

npm run build

Или откройте папку через сервер: python3 -m http.server 8000 → http://localhost:8000. Если папку скачали архивом — проще взять свежую версию из репозитория: там собранные файлы уже лежат.
