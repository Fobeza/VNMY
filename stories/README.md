# Папка stories — контент

```
stories/
├── <вселенная>/
│   ├── universe.json                         мир: название, описание, обложка
│   ├── cover.webp                            обложка (необязательно)
│   └── novels/
│       └── <новелла>/
│           ├── story.json                    сценарий новеллы
│           └── assets/                       фоны, спрайты, обложка
├── _template/                                заготовки (сборка их игнорирует)
├── index.json                                СОЗДАЁТСЯ сборкой: манифест
└── builtin.js                                СОЗДАЁТСЯ сборкой: для file://
```

Правила коротко:

- новая вселенная = новая папка с `universe.json` (id = имя папки, латиницей);
- новая новелла = папка в `stories/<вселенная>/novels/` с `story.json`;
- в `story.json` поле `"universe": "<id вселенной>"`;
- пути к картинкам — от папки новеллы: `assets/bg.webp`;
- папки, начинающиеся с `_` или `.`, сборка пропускает — там лежат шаблоны и служебные файлы;
- после добавления папок: `npm run build` (обновит манифест и `vnmy.html`).

Подробно: [../docs/ai-guide.md](../docs/ai-guide.md) и [../docs/format.md](../docs/format.md).

В поставке нет готовых вселенных и новелл: здесь лежит только `_template/`
с заготовками. Вселенные добавляются новыми папками (см. выше), после чего
`npm run build` обновляет манифест и автономный `vnmy.html`.
