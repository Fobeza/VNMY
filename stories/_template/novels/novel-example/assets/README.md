# Картинки истории

Положите сюда:

- `bg-start.webp`, `bg-end.webp` — фоны 1080×1920 (9:16);
- `hero-neutral.webp`, `hero-smile.webp` — спрайты с прозрачностью, высота ~1500 px.

Потом поменяйте в `story.json` путь `assets/…` и, при необходимости, имена эмоций.
Любую картинку можно выбрать и заменить прямо в редакторе: вкладка «Сцена» → «Фон»,
вкладка «История» → персонаж → спрайт.
