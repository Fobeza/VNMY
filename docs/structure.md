# Структура проекта

Дерево и зона ответственности каждого файла. Если сомневаетесь, куда что класть —
сначала посмотрите здесь, потом в [ai-guide.md](ai-guide.md).

```
VNMY/
├── index.html                 единственная страница: четыре экрана + шаблон сцены
├── vnmy.html                  СБОРКА: всё в одном файле (телефон, открытие с диска)
├── bundle.js                  СБОРКА: js/* обычным скриптом для file://
├── start.sh                   локальный сервер одной командой
├── AGENTS.md                  короткая инструкция для ИИ-агента
├── package.json               команды build/test и dev-зависимости
├── package-lock.json          зафиксированные версии dev-зависимостей
├── .gitignore                 зависимости, логи, исходники картинок и временные файлы
│
├── css/
│   ├── base.css               токены темы, каркас экранов, библиотека, вселенные
│   ├── player.css             сцена 9:16, спрайты, реплики, выборы, шторки/меню
│   └── editor.css             редактор: вкладки, поля, превью, медиатека
│
├── js/
│   ├── app.js                 точка входа, навигация: вселенные → новеллы → игра
│   ├── store.js               localStorage: библиотека, свои вселенные, сохранения,
│   │                          импорт/экспорт, прогресс, настройки
│   ├── universe.js            модель вселенной: схема, id из названия, «Без вселенной»
│   ├── format.js              модель новеллы: схема, нормализация, проверки, утилиты
│   ├── library.js             экран «Вселенные» + форма создания/правки вселенной
│   ├── novels.js              экран «Новеллы вселенной»: карточки, меню новеллы, импорт
│   ├── player.js              прохождение: меню, журнал, сохранения, настройки
│   ├── engine.js              сцена: фон, спрайты, погода, эффекты, переходы
│   ├── expr.js                безопасный язык условий и подстановок (без eval)
│   ├── weather.js             дождь/снег/пыль/лепестки на canvas
│   ├── editor.js              редактор: состояние, undo/redo, автосохранение, меню
│   ├── editor-tabs.js         вкладки редактора «Шаг», «Сцена», «История», «Медиа»
│   ├── editor-ui.js           элементы форм и загрузка картинок (сжатие в WebP)
│   ├── ui.js                  тост, шторка, подтверждение
│   ├── util.js                el(), $, debounce, download, uid…
│   ├── icons.js               SVG-иконки пунктов меню
│   └── version.js             номер версии приложения
│
├── stories/                   КОНТЕНТ (единственное место, куда добавляют новое)
│   ├── index.json             СБОРКА: манифест — какие вселенные и новеллы есть
│   ├── builtin.js             СБОРКА: те же данные для file://
│   ├── README.md              короткая памятка по папке
│   ├── _template/             заготовки: copy-paste для новой вселенной/новеллы
│   │   ├── universe.json
│   │   └── novels/novel-example/{story.json, assets/README.md}
│   └── <вселенная>/           ваши вселенные: universe.json + novels/<новелла>/ + картинки
│
├── tools/build.mjs            сборка: манифест, bundle.js, builtin.js, vnmy.html
├── tests/
│   ├── run.mjs                интеграционные проверки (jsdom + esbuild)
│   └── fixtures/
│       └── integration-story.js  синтетическая история только для тестов
├── docs/
│   ├── ai-guide.md            как добавить контент и не сломать проект
│   ├── structure.md           этот файл
│   └── format.md              полный справочник по story.json
├── assets/                    иконки PWA
├── sw.js                      service worker (офлайн), версия кэша = версия приложения
├── manifest.webmanifest
├── CHANGELOG.md
└── README.md
```

## Поток данных

```
stories/<вселенная>/…            (файлы на диске)
        │  npm run build
        ├── stories/index.json    манифест: вселенные + список новелл
        ├── stories/builtin.js    те же данные обычным скриптом (file://)
        └── vnmy.html             всё + картинки в data: (одним файлом)
                │
index.html / vnmy.html → js/app.js → store.loadLibrary()
        ├── встроенные вселенные (файлы или сборка)  — только чтение
        ├── свои вселенные и новеллы (localStorage)  — правятся в редакторе
        └── «Без вселенной»                          — новеллы без story.universe
                │
       экран «Вселенные» (js/library.js)
                │ тап по карточке
       экран «Новеллы вселенной» (js/novels.js)
                │ тап по новелле                ⋯ → меню новеллы
       игра (js/player.js + js/engine.js)   редактор (js/editor*.js)
```

## Ключи localStorage

| Ключ | Что внутри |
|---|---|
| `vnmy:index` | порядок своих новелл (массив id) |
| `vnmy:story:<id>` | сама новелла (`story.json` без `readOnly`) |
| `vnmy:universes` | свои вселенные (массив `universe.json`) |
| `vnmy:saves:<id>` | автосейв и три ручных слота |
| `vnmy:seen:<id>` | прочитанные шаги (для «пропускать прочитанное») |
| `vnmy:settings` | скорость и размер текста, пропуск прочитанного, не гасить экран, меньше анимации |

Всё вместе — около 5 МБ на браузер: картинки лучше держать файлами в
`stories/…/assets`, а в браузере хранить текст и правки.
