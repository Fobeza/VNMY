# Сверка интерфейса VNMY с выбранными макетами

Сетка рассчитана на вертикальный телефон. Фон `#141923`, панели `#1c222e`, акцент `#8d9af2`, системный шрифт, тонкие границы, простые контурные иконки. Внутренние отступы страницы 22 px, основные кнопки 48 px, интерактивные цели не меньше 44 px.

| Экран | Реализация по референсу |
|---|---|
| Настройки | Три вкладки: Текст, Звук, Управление. Заполненная часть ползунка окрашена акцентом, значение справа; сброс внизу. |
| Звук | Общая громкость, музыка, звуки, голоса, звук в фоне, настоящая проверка звука. Каналы подключены к воспроизведению через Web Audio GainNode с запасным HTML audio. |
| Управление | Карточка трёх жестов, пропуск прочитанного, подтверждение пропуска, скорость авточтения, вибрация. Неподдерживаемая устройством вибрация выключена. Дополнительные настройки свёрнуты. |
| Сохранение | Шапка VNMY и настройки; большой заголовок и название истории; Ручные / Авто / Быстрые; справка «Сейчас» о текущей сцене, сетка 2×3: пустые ячейки компактные с плюсом, заполненные — с крупной миниатюрой; основная кнопка. |
| Загрузка | Та же шапка и вкладки; список реальных сохранений с миниатюрой слева; кнопка загрузки. Быстрый слот независим от ручных. |
| Журнал | Шапка VNMY, заголовок, подпись сцены, имена цветом персонажа и разделители; собственный выбор подписан «Вы»; переход к последней реплике внизу. |
| Галерея | Иллюстрации / Музыка, фактический счётчик, две колонки иллюстраций, закрытые ячейки без спойлеров. Открытые музыкальные дорожки можно прослушать. |
| Пауза | Центральная карточка, заголовок и сцена, основная кнопка «Продолжить» перед списком действий, контурные иконки. Действия сгруппированы: «Игра» (сохранить, загрузить, галерея), «Вид» (масштаб, скрыть интерфейс, настройки), затем «В главное меню». Журнал — на нижней панели. На низких экранах меню помещается без прокрутки. |
| Об истории | Обложка целиком (поля заполняет её размытая копия), название, жанры, автор, число сцен и время чтения, описание, прогресс, продолжение и новая игра, сохранения и галерея. |
| Импорт | Выбор .vnmy, выбранный файл и состояние, обложка и проверка содержимого; запись в библиотеку только по кнопке «Добавить». |

## Данные и допустимые отличия

- Названия, изображения, количество открытых материалов и даты берутся из новеллы и сохранений. Образцовые «3 из 12», жанры и музыку из макета не подставляем в реальные истории.
- Старые .vnmy без аудио работают как прежде; вкладки звука и музыки остаются доступными, а пустая музыкальная коллекция объясняет отсутствие дорожек. Для проверки громкости есть короткий тестовый тон.
- Масштаб персонажей — дополнительная функция вне исходных макетов. Доступен из меню игры и вкладки «Текст»; диапазон 50–300%, общий для любых историй.
- Список автосохранений показывает реально существующие записи. Ненастоящие записи ради внешнего совпадения не создаются.
- Сценарий, прогресс, позиции и фиксированные якоря спрайтов не зависят от оформления страниц.

## Проверка

`npm run check` проверяет настройки, загрузку, быстрый слот без вытеснения ручных, аудиоканалы, формирование .vnmy, предпросмотр без записи, жесты и маршруты. `npm run check:browser` проверяет четыре размера экрана и сохраняет реальные скриншоты каждого раздела в артефакт `mobile-ui-screenshots` в GitHub Actions. Скриншоты используют синтетическую тестовую новеллу, а не пользовательский сюжет.
